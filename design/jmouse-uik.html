Principles

The television is not a bigger monitor. It is read from three metres, driven with five buttons, and watched in the dark. Every decision below follows from those three facts.

RuleWhat it means on a screen
The cursor is the focusExactly one element is in hand. It wears a 4px aqua rule 6px outside its edge and lifts 6%. Nothing else on the screen looks like that — the aqua is spent on focus, the primary action, a link and progress, and on nothing decorative.
Nothing readable under 22pxBody 28px, captions 24px, eyebrows 22px tracked. Titles 64–80px. The pairing code 160px. Every size is a token; a screen does not invent one.
Rows, not pagesSideways within a row, up and down between rows. A row remembers where you left it. A focused row lands on the same lane, 192px from the top, so the eye never chases the cursor.
Nothing hides behind hoverThere is no pointer. Whatever a web hover would reveal is either always visible, or comes with focus.
No typing that can be avoidedThe television is admitted with a six-digit code confirmed on the server, never with a password. A profile PIN is four digits on a pad. Search is a letter grid, results arrive as letters land.
The playback decision is visibleDirect play or Transcode is on the title page and in the player's chrome, because it is the first question when the picture stutters.
Dark only, four radii, one hueKitsu's dark set on :root. Radius 12px on controls, 16 on surfaces, 20 on media, 24 on a dialog. Depth is drawn with rules and two steps of surface, never with shadow. The one hue is the accent — the mark's own ember, and eight others.

Focus

One treatment, everywhere. A 4px rule in --kt-accent-text, 6px outside the element, and a lift of 6% for tiles and 3% for buttons. Text in hand goes from muted to full ink; a surface in hand rises one step.

Inception2010 The Matrix1999
in hand: tile · primary · secondary · chip — the rest of the row is at rest

The engine in tv.js mirrors :focus into .is-focused, because a browser window in the background stops matching :focus while a television never loses it. Every focus rule is written as :is(:focus, .is-focused).

Buttons

Three weights, one height (72px). Primary is the aqua fill and there is one per screen; secondary is an ink outline; quiet is text. A hint in mono after the label carries the number the button acts on.

Tiles

A poster (2:3), a still (16:9), a text tile for a genre, a square for a person — one frame, one caption. When artwork is missing the frame draws itself from the name and never pretends to be a photograph.

Shelves & walls

A shelf is a heading and a row that scrolls sideways under the cursor. A wall is the catalogue grid. Both start at the gutter; a row's padding is the gutter too, so the first tile lines up with the heading and the last one can still be reached.

Deck & rail

The deck is the command bar: the brand, four bays, the server light, the clock and the profile. It stays navy and stays put; UP from the first row reaches it. The rail is the facet list on the left of a catalogue; the chosen facet keeps an index tab.

Player

The seek bar is one control: in hand it wears the ring 12px out, LEFT/RIGHT step it. Timecodes are 32px mono with tabular figures; the right one counts down and says when the film ends by the clock, which is the number a person on a sofa actually wants.

Dialog

A panel on the scrim, focus trapped inside, BACK closes it and returns the cursor to where it was. There is no close button in the corner — the remote has one.

Every screen has its empty, waiting and refused states drawn; the mock-ups switch between them with the number keys 1–4, listed in each page's data-states. Empty states sit on the ruled ground so a blank library still reads as an instrument.
